# Workspace setup contract

Use the five agreed user-record homes: profile/ (background, capabilities, direction and development), projects/ (purpose, contribution, learning and work links), brand/ (positioning, audiences and visual guidance), assets/ (reusable outputs) and research/ (selected references). These differ from installable skill categories. Map existing files rather than require migration; create only needed records.

The entire workspace is private and can live in any Markdown-capable storage. Record the canonical source map, root/provider, read/write boundaries, optional tracker and publication permissions in an existing career README or chosen index. Use headings and relative links; no mandatory YAML, database or integrations.

Within assets/, drafts/ holds proposals and staged/ holds explicitly approved material. services.md describes destinations, account URLs, intended use, relevant reusable assets and available inspection/update methods. Reuse common content; add adaptations only when needed. Staging is not proof of publication. External content establishes actual published state; discrepancies require the user's choice, with factual conflicts flagged before importing changes.

Within research/, companies/, opportunities/ and profiles/ hold selected references; archive/ holds guided archival history. Shortlist first, then retain some/all/none as chosen or explicitly authorized. Keep links, checked dates and useful observations; comparator resumes remain links. Review on request; age alone does not justify archival. Archive under user guidance, leave deletion manual, and ask before acting on stale material encountered during other work.

Keep profile facts, aspirations, evidence and presentation distinct. Link records instead of duplicating them; a project is not automatically evidence. Read current records before editing, preserve unrelated changes, follow the chosen write workflow and confirm saves. With missing access, provide a proposal without claiming success. Every skill remains usable from supplied input without setup.
