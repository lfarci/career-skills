# Credly, Microsoft Learn and other credential pages

These pages show badges and transcripts; the platform writes most of the text. Copy is usually a short list:

- Which badges or certifications to feature or pin, with their dates from `profile/qualifications.md`.
- Expired or superseded items to hide, when the platform allows.
- The public URL to link from LinkedIn, GitHub or the site.

Badges seen only on the page and missing from the profile go to the user as proposed profile updates; never add them silently.
