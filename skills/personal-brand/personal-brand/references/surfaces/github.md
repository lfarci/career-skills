# GitHub profile

Patterns, not text to copy. The profile README lives in a public repo named exactly like the username (`<user>/<user>/README.md`). Pinned repos (up to 6) and the profile bio carry as much as the README.

## Limits (approximate, checked 2026-10)
- Bio: 160 characters. README: no practical limit; keep it to one screen.

## Variant A: minimal
```markdown
# Hi, I'm <Name>
<Role> working on <domain/stack>. <One confirmed proof or current focus>.

- Currently: <what you build or learn now>
- Find me: [LinkedIn](<url>) · [Site](<url>)
```

## Variant B: consultant / freelance
```markdown
# <Name>, <Role>
I help <client type> <outcome>. <Stack> in production since <year from records>.

## What I do
- <Service 1>
- <Service 2>

## Selected work
- [<project>](<link>): <one-line confirmed result>

Available for <type of work>: [contact](<url>)
```

## Variant C: open-source maintainer
```markdown
# <Name>
Maintainer of [<project>](<link>), <what it does in one line>.

## Projects
| Project | What | Status |
| --- | --- | --- |
| [<repo>](<link>) | <one line> | active |

## Contributing
<How to get involved, or a link to CONTRIBUTING.md>
```

## Tips
Link only real repos and URLs from the records. Skip stats widgets and badge walls unless asked; they age fast and add no facts.
