# Banner and icon sizes per surface

Approximate values, checked 2026-10; platforms change them, so recheck the upload screen when exact pixels matter. Design one master at 3000×1000 (3:1) or larger, keep name and role inside the centre safe area, and derive each crop.

| Surface | Asset | Size (px) | Ratio | Notes |
| --- | --- | --- | --- | --- |
| LinkedIn profile | Background banner | 1584×396 | 4:1 | Profile photo covers the lower left; keep text centre-right, safe zone about 1350×220 centred. |
| X | Header | 1500×500 | 3:1 | Avatar overlaps lower left; top and bottom crop on mobile. |
| Bluesky | Banner | 3000×1000 (1500×500 fine) | 3:1 | PNG/JPEG, max 1 MB. |
| GitHub repo | Social preview | 1280×640 (min 640×320) | 2:1 | Settings → Social preview; under 1 MB. |
| GitHub profile README | Header image | ~1280×320 | 4:1 | Optional; rendered at README width, keep text large. |
| Personal site | Favicon from the logo | SVG + 32×32, 180×180 (Apple touch), 512×512 PNG | 1:1 | Simplify the mark; test at 16 px. |
| Personal site | Social card (Open Graph) | 1200×630 | ~1.91:1 | Only when a site is confirmed. |

Avatars and profile photos are out of the MVP; most people use a photo there.
